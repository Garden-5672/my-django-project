💡 대시보드 내 다운로드 기능 활용 안내

본 도구는 별도의 오프라인 파일 다운로드 없이 대시보드 내부에서 결과 및 리포트를 직접 다운로드할 수 있도록 구현되어 있습니다.

  • 대시보드 접속 후 계산된 정산 내역 및 분석 데이터를 Excel 형태로 바로 내보낼 수 있습니다.
  • 데이터의 최신 상태 유지 및 보안을 위해 웹 대시보드 상에서 작업을 권장합니다.

외부 서버에 개인 금융 데이터를 저장하지 않고, 대표님의 개인 구글 드라이브와 대시보드를 직접 안전하게 연결하는 방식입니다.

  • 1단계: 전용 데이터 저장소 생성 (사본 복제)

    아래 구글 시트 템플릿에 접근한 후 [사본 만들기]를 실행하여 대표님 소유의 드라이브에 시트를 생성합니다. (원하신다면 파일 이름을 자유롭게 변경하셔도 괜찮습니다.)

    🔗 Profit First 구글 시트 템플릿 복제 링크
  • 2단계: 자동화 보안 권한 설정 (공유)

    생성된 대표님의 구글 시트 우측 상단 [공유] 버튼을 클릭하고, 대시보드 전용 API 이메일을 [편집자] 권한으로 추가해 주세요.

    profit-first-api@biztool-lab.iam.gserviceaccount.com

    * 조직 외 사용자 안내가 뜨더라도 표준 자동화 보안 절차이므로 안심하고 승인하셔도 됩니다.

  • 3단계: 대시보드에 URL 및 인증키 입력

    1. 상단 주소창에 있는 구글 스프레드시트 전체 주소(URL)를 복사합니다.
    2. 다시 Profit First 대시보드 화면으로 돌아옵니다.
    3. 사이드바 또는 상단에 마련된 [내 구글 시트 주소 (URL) 입력]란에 복사한 주소를 그대로 붙여넣어 줍니다.
    4. [연결 완료 및 구글 시트 저장] 버튼을 누르면 모든 세팅이 안전하게 종료됩니다.
